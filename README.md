# AlphaPullDown_GoogleColab
AlphaPullDown for Google Colab

## 概要
AlphaPulldown を Google Colab 上で簡単に実行するための設定およびサンプルノートブックです。
Colab の GPU 環境を活用して AlphaPulldown の解析を手軽に行うことを目的としています。

## 必要環境
- Google Colab
- CUDA 対応 GPU とドライバ
- Python 3.x
- JAX
- AlphaPulldown で要求されるその他のライブラリ

## 使い方
1. リポジトリに含まれる `AlphaPullDown.ipynb` を Colab で開きます。
2. ノートブック内のセルを上から順に実行してください。
3. ノートブックは次のセクションで構成されています。
   - **セットアップ**: 必要なライブラリのインストールと環境設定。
   - **データの準備**: 入力データのアップロードや前処理。
   - **解析の実行**: AlphaPulldown を用いた解析の実行。
   - **結果の確認**: 出力結果の確認と保存方法。
