# AlphaPullDown_GoogleColab
Run AlphaPulldown on Google Colab

## Overview
This repository provides a configuration and sample notebook for running AlphaPulldown on Google Colab with ease.  
By leveraging Colab’s GPU environment, you can quickly perform AlphaPulldown analyses without complex setup.

## Requirements
- Google Colab  
- CUDA-compatible GPU and drivers  
- Python 3.x  
- JAX  
- Additional libraries required by AlphaPulldown  

## Usage
1. Open the `AlphaPullDown.ipynb` notebook included in this repository with Google Colab.  
2. Run the cells in order from top to bottom.  
3. The notebook consists of the following sections:  
   - **Setup**: Install required libraries and configure the environment.  
   - **Data Preparation**: Upload and preprocess input data.  
   - **Run Analysis**: Perform the analysis using AlphaPulldown.  
   - **Check Results**: Review and save the output results.
